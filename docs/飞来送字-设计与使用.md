默认从目标所在显示器的四边外侧入场，沿曲线飞向光标附近；携字成员牵着小字牌，聚拢时字牌上浮，随后整群散开淡出。点击会触发较大的聚集，不附带虚构的键入文字。快速连续打字会合并短时间内的发射，并更新正在飞行的字牌，保证有成员真正抵达而不是不断重置起点。池子最多 8 组、64 个成员。

字牌默认距输入点约 70 个逻辑像素，临近屏幕底边会翻到上方。绘制避开光标附近的文字行。可切换字牌距离、关闭字母展示、降低荧光亮度，或开启轻柔模式，改成短距离浮现；暂停、隐藏和演示功能沿用原菜单。

安全输入会清除群体与字牌。系统输入事件的 Unicode 是按键字符，不承诺等同于中文输入法的最终上屏文字。微信等应用是否能精确取到光标，仍取决于它们提供的辅助功能信息；新增外观不改变这个限制。点击可直接使用真实点击位置；无光标位置时可使用既有手动备用目标，但当前字符提取仍需要有效的文本光标信息。

实现使用原生 Core Graphics 矢量、Bezier 飞行曲线、独立群体时钟与短生命周期池，不需要新图片素材或第三方动画运行时。每屏透明窗口透传鼠标、不抢焦点，显示器布局变化会清理旧轨迹。日志仅保存计数与状态，不记录输入字符。

源码：SwarmMotion.swift、SwarmRendering.swift、SwarmApp.swift。预览由实际原生渲染器生成，合成演示不能证明所有第三方应用输入兼容。
