# InteractPet

会把字母送到输入位置的 macOS 桌宠。当前版本 **v0.10.0**，应用显示名称为“奶芋与朋友们 / Taro Octopus”。

提供 22 个可切换外观，包括紫色八爪鱼、变色龙、云朵、机器人和五只排排坐的小猫。打字或点击时，角色伸出触手、舌头、尾巴等递送字母；递送可以与行走、攀爬和群体摇摆同时进行。

五猫角色使用独立身体骨骼、四肢 IK、脊柱与尾巴样条。尾巴包含预摆、伸出、轻点、回收和余摆，也有轻扫、问号卷尾、绕尾与甩尾等待机动作。巡游、五猫摇摆和尾巴小动作都可以独立关闭。

## 飞来送字（v0.10）

新增 16 款群体送字效果：萤火虫、彩虹粒子、小蜜蜂、蝴蝶、星星、流星、泡泡、水母、花瓣、雪晶、幽灵、小鱼、爱心、纸飞机、符文和电浆。它们从屏幕四边飞入、携字聚拢并发光散开，支持快速输入、真实点击、暂停隐藏、低亮度和轻柔模式。菜单中的原角色和群体效果可以互相切换。

[16 款设计与使用说明](docs/飞来送字-设计与使用.md) · [样式清单](docs/swarm-styles.json)

## 编译运行

需要 macOS 13 或更新版本，以及 Xcode Command Line Tools。本次已验证的安装版本为 Apple Silicon。

```sh
xcode-select --install # 已安装则跳过
git clone https://github.com/newsun-boki/InteractPet.git
cd InteractPet
zsh ./build.sh
open "dist/Taro Octopus.app"
```

编译产物默认放在仓库内的 `dist/`，编译缓存保存在仓库内的 `.cache/`。也可以通过 `TARO_APP_OUTPUT` 指定应用输出路径。构建采用本地临时签名；首次运行需在“系统设置 → 隐私与安全性 → 辅助功能”中授权当前应用。源码重新构建后，系统可能需要重新确认授权。

## 使用

通过菜单栏的章鱼图标切换角色、调整字牌与输入位置的距离，以及开启或关闭动作。默认使用系统辅助功能接口定位输入位置；微信等没有暴露可靠光标位置的应用仍有兼容性限制。点击交互按实际点击位置响应。该项目目前不包含独立输入法组件。

## 源码结构

- `work/octopus-pet/Sources/`：窗口、全局输入监听、光标追踪、渲染、角色动画和群体行为。
- `work/octopus-pet/Assets/`：编译需要的透明素材、外观配置及生成提示词。
- `work/octopus-pet/Tests/`：运动、连续送字、五猫骨骼、尾巴样条等测试与原生预览程序。
- `work/octopus-pet/Tools/`：制作过程中的图册生成与检查工具；这些工具另需已生成的图册文件，应用编译不依赖它们。
- `skills/desktop-courier-pet/`：可复用的桌宠制作 skill。
- `docs/`：完整创作提示词与 v0.9 动画验证记录。

应用采用 Swift、AppKit、Core Graphics 与系统辅助功能接口。无需安装 Node.js、Rust 或 Live2D 来编译当前原生桌宠。角色由生成的透明素材和程序化动画共同绘制。

这个仓库保存当前可编译的源码与素材；历史安装包、旧工程、编译缓存和完整制作归档保存在 ORICO 项目目录。

## 验证

`zsh scripts/verify-swarm.sh` 运行群体、连续递字、五猫回归与原生菜单/偏好恢复检查。附加 `--preview` 可使用 ffmpeg 导出 16 段实际渲染器的演示视频，产物位于 `validation/swarm-v010/`，不会提交到 Git。真实输入的最终验证需在已授权运行的应用中打字和点击。
