# 完整创作提示词

下面正文可复制到新的编程助手会话。替换方括号参数即可；没有填的细节由助手根据既有工程合理决定。

---

请帮我制作一个可实际运行的原生桌面打字桌宠，并完成素材、动画、程序接入、验证和可运行交付。优先检查工作区中的现有工程并继续开发，不另起无关演示。只在缺少会影响架构的必要信息时询问，普通实现细节自行判断并持续完成。

## 角色设定

- 目标平台：[macOS；若现有项目不同，以明确确认的平台为准]
- 名称：[奶芋团子 / 五只小猫·排排坐 / 自定义]
- 数量和形态：[单个 Q 版紫色八爪鱼，八条触手 / 五只不同花色的小猫并排坐]
- 视觉：[软糯、圆润、可爱，柔和奶油色，高质量透明素材，缩小后轮廓仍清楚]
- 递送方式：[八条触手依次伸出 / 五只猫轮流伸出卷尾 / 舌头、藤蔓、飘带等]
- 平时位置：[屏幕右下角，避开 Dock 与屏幕边缘]
- 身体动作：[坐着同步摇摆；或者允许可关闭的行走、攀爬]
- 工程位置：[当前工作区；先发现实际路径]

## 我想要的交互

1. 我打字时，桌宠从身体伸出对应的器官，延伸到实际文本插入位置，让人感觉字符是它递来的。鼠标点击也能伸到点击位置。用全局屏幕坐标处理跨应用、多屏、负坐标和缩放。
2. 先验证“当前输入位置”是否能可靠获取，在原生文本框、浏览器和我关心的应用中记录支持情况。取不到时诚实提示并保留点击响应或明确的演示模式，不把猜测坐标当作已兼容。全局键盘事件不等于输入法最终提交的汉字；确有需要时再单独设计输入法接入方案。
3. 多肢体轮流出动；快速连续输入不形成无限队列。只有一条舌头等单器官角色，伸着时也必须持续切换最新字符，不能碰到目标后就变成空白。
4. 展示可爱的小字牌，由爪子、触手或专用夹持部位托着。字牌放在离末端稍远的位置，不挡住正在输入的文字，距离可调。停止输入后自然淡出并收回。
5. 伸出时身体有轻微拉力反应、回弹或重心调整。打字和点击必须与行走、攀爬、摇摆同时进行，不能中断这些动作。根部跟随当前身体姿态，不能悬空或因转身瞬移。
6. 提供角色切换、大小、显示屏选择和暂停等与现有产品一致的控制。行走/攀爬可以独立关闭，关闭后固定在右下角仍可送字。五猫同步摇摆另有独立开关。用户设置跨换角色、换屏幕和重启保存。

## 素材与动作质量

使用图片生成制作真实角色素材，保留原始 PNG、完整提示词和透明背景。按动画需求决定是分层素材、独立图集还是可变形网格；不要用整张静态图平移代替走路和攀爬。若用 Live2D、骨骼或程序化软体，交付实际可加载的模型或代码，不只给概念图。

动作应符合角色构造：行走要有支撑与摆腿，攀爬要有抓取、拉起和换手，软体要有连续曲线和回弹。坐姿摇摆围绕脚底支点，头、耳朵和尾巴有小幅跟随。群体动作分为队伍调度与个体骨骼两层；支撑期锁定足端，摆动期抬脚，脊柱与尾巴可以沿 spline 变形。关闭群体互动时平滑回座，字母递送继续。依据测量后的美术锚点绑定，不凭画布中心猜位置。原图自带脸时避免再次叠加程序化眼睛。

五猫预设：严格五只，从左到右为橘猫、奶油猫、银灰猫、三花猫、黑白猫；各自轮廓完整、同一坐姿基线，独立绑定。五只身体按同一节奏左右摇摆，眨眼可错开，耳尾轻动；保留排排坐待机；如需屏幕互动，做成可关闭的依次跟随、领队起跳扒边、队友抬头抬爪回应和回队。避免把整组当成一张移动贴图；单独安排边框占用，保证成员不互穿。每次打字轮到一只猫伸出尾巴，用小卷尾托住字牌，其余猫继续摇摆。尾巴待机时可以轻扫、卷成问号、绕尾或甩尾，伸出有预摆、波动、接触和回收余摆；尾巴小动作可独立关闭。若用户指定爪子递送，则保留爪子方案。

章鱼预设：奶芋紫色团子身体，八条软体触手轮流伸向输入/点击位置。触手保持连续粗细和根部连接，吸盘随曲线分布，身体随拉力轻微形变。字符牌从末端向身体方向退开一段距离，避免挡住输入区。

## 实现边界

覆盖窗口透明、鼠标穿透、不抢焦点。坐标转换集中处理。身体移动、递送肢体、字牌生命周期分别更新；明确暂停才统一停止。异步字符回调要有角色代次与输入序号保护，过期回调不能覆盖新字。

不记录或上传输入内容，密码/安全输入框不提取和显示字符。权限缺失时解释具体原因并引导系统正常授权；已有授权先实际验证，不反复要求重开，不修改系统隐私数据库。

## 验证和交付

请实际编译运行，并依据本次改动验证：连续快速打字、点击、单器官字母更新、多器官轮转、身体移动时送字、根部连续、停止后的回收、动作关闭与重启恢复、换角色、换屏幕和边界可见性。新增角色不得破坏原有角色。

输出使用真实渲染器生成的动画预览，检查关键动作帧。说明哪些是数学模拟、哪些是抽帧检查、哪些是真实输入测试。提供可运行应用或启动命令、源码与素材位置、角色选择和关闭动画的方法。保留既有兼容性限制，不用“所有应用都适配”等未经验证的结论。

完成后把本次角色的锚点、动画参数、素材提示词与验证结果保存，方便以后继续新增角色。
